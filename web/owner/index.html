RLYA Mainnet Launch Console

This page handles the irreversible RLYA token creation and allocation only after the permanent Solana Mainnet program has been deployed from your own computer. It never asks for a seed phrase or private key.

Keep the public presale switch OFF during this entire sequence. First deploy the permanent program with the owner-controlled local deployment script. Then use this console to prepare RLYA. Public buying is opened only after the finished Mainnet state is independently verified.
Safer staged launch: preparation creates exactly 839,000,000 RLYA, funds every allocation and permanently removes mint authority while the sale remains DRAFT. Activation and pause are then executed atomically in one Solana transaction, so there is no public ACTIVE window between transactions.
