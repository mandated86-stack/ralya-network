✓ Fixed-supply economics

PASS

The lifetime maximum remains 839,000,000 RLYA. The public base presale allocation is 288,000,000 RLYA and a separate fixed 14,400,000 RLYA reserve covers the maximum possible 5% Buy + Stake bonuses inside the same lifetime supply. The founder allocation remains 83,900,000 RLYA with a 365-day lock beginning from actual public RLYA launch Day 0.

✓ Deterministic presale pricing

PASS

The presale starts at $0.003000 per RLYA and follows the reviewed deterministic demand-based pricing curve. Website and authorized private allocations share the same base allocation accounting; there is no arbitrary public price override.

✓ Verified pre-launch USDC allocation layer

PRIVATE TESTING

Checkout authenticates the buyer wallet, locks an exact short-lived allocation quote, then verifies the confirmed Solana USDC transaction independently before recording expected RLYA. The current production website keeps real checkout disabled while the final release-policy path is re-verified end to end.

✓ Presale release policy

CONFIGURED

Standard presale buyers are scheduled to receive actual purchased RLYA 1 day before public token launch. Buy + Stake buyers receive a fixed 5% additional RLYA from the dedicated reserve and unlock their base allocation plus bonus 21 days after public launch.

✓ Opening readiness gate

PASS

Allocation access cannot be switched to OPEN unless the server can reach Solana Mainnet and independently verify the configured treasury USDC receiving account. RLYA Mainnet deployment remains the next major production phase.

✓ Referral accounting

PASS

The fixed referral rate is 1% of gross referred USDC. The buyer receives the normal RLYA allocation, 1% is routed to the locked referrer and 99% to the configured presale treasury. Self-referrals and direct two-wallet referral loops are rejected.

✓ Owner pre-launch controls

READY

The owner can preflight, open, pause or close allocation access, record legitimate private/off-site allocations, inspect totals, look up buyer allocations, update the public build stage and export a hashed distribution manifest. Public status controls cannot by themselves activate a token launch.

✓ Mainnet reconciliation design

READY CODE

The production program includes a separate pre-launch reconciliation path so website allocations can later import their USDC/referral accounting and advance total sold without being mislabeled as private/off-site sales. Deterministic per-wallet receipt PDAs are designed to prevent duplicate distribution.

✓ Solana program test foundation

PASS
