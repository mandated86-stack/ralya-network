# Contributing

1. Keep RLYA Coin/Network code separate from the unrelated Ralya Protest App.
2. Do not add token minting, transfer taxes, refund/claim states or hidden price overrides.
3. Add tests for changes to economic logic.
4. Run `python -m unittest discover -s tests -v` and `python scripts/audit_source.py`.
5. Treat compiled/deployed status as evidence-based; publish addresses and transaction signatures when applicable.
